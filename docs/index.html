Project Overview

This project generates a structured Excel workbook for managing customer records and supporting CRM-style data workflows. The implementation focuses on controlled data entry, validation, reporting, data quality checks, and activity tracking.

Structured Data

A dedicated customer database with a defined 10-field schema and Excel table structure.

Data Validation

Controlled dropdown lists help maintain consistent customer data.

Dashboard

Dynamic KPI formulas summarize customer status and database activity.

Data Quality

Missing-field checks help identify incomplete customer records.

Activity Tracking

A structured activity log records customer-related interactions and events.

User Instructions

Built-in documentation explains the workbook workflow and field definitions.
